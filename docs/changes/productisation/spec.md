# Spec

One installed cac command exposes fleet, work, jobs, context and SDLC features while preserving existing workspace commands. A clean wheel contains generic code and templates only. Reviewable saved plans bind exact source and observed ownership; apply refuses stale plans. Diagnostic and recovery behavior must be explicit. Clean installation, repeated application, drift refusal, independent review and actual receiving-host use are acceptance evidence. Public publication and real second-host verification remain distinct release gates.
