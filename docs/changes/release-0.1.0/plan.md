# Plan

Primary owns architecture, CLI/bootstrap/GitHub integration, packaged templates, documentation, workboard and release. One implementation worker owns the filesystem engine and focused regressions; another owns lifecycle and gauntlet. A separate reviewer checks containment and provider behavior read-only. Integrate returned evidence, reproduce failures, repair in bounded rounds, then run the complete suite and a wheel-installed acceptance path in a temporary workspace. Inspect public files before creating and pushing the authorized public repository. Publish a tagged release only after hosted CI and release gates; bootstrap a separately private instance and verify its visibility and clean remote readback. Rollback uses reviewed prior definitions and source versions; no automated resource deletion.
